# VEX 赛程管理助手 (iOS/PWA 版)

一款专为 VEX 机器人竞赛教练和队员设计的硬核赛程管理工具。本版本针对 iOS 生态及移动浏览器环境进行了深度优化，采用 PWA (Progressive Web App) 架构，提供媲美原生应用的沉浸式体验。

## 🌟 核心特性

* **iOS 像素级适配**：针对 iPhone/iPad 的刘海屏、灵动岛以及底部安全区域（Safe Area）进行精准适配，确保 UI 不被遮挡。
* **PWA 沉浸式模式**：通过“添加到主屏幕”即可全屏运行，彻底隐藏浏览器地址栏与工具栏，享受 100% 的原生 App 视觉感。
* **极致兼容性**：采用特殊优化过的 PDF 解析引擎，完美兼容老款 iPad 设备，彻底解决“组件加载失败”问题。
* **零延迟本地存储**：数据基于 LocalStorage 实时存储，无需联网，无后端延迟，赛场断网环境下依然稳定可靠。
* **红蓝阵线设计**：视觉上沿袭 VEX 经典的红蓝联队色，配合极简几何 UI，信息层级清晰分明。

## 🚀 快速开始

1.  **准备文件**：确保你的项目目录下包含 `index.html` 和 `icon.png` (建议 1024x1024 像素)。
2.  **上传托管**：将代码推送至你的 GitHub 仓库。
3.  **开启 Pages**：在 GitHub 仓库的 `Settings > Pages` 中，选择 `main` 分支并保存。
4.  **访问网址**：等待 1 分钟后，你将获得一个专属的 `https://<your-name>.github.io/<repo-name>/` 链接。

## 📲 安装指南 (iOS 用户必读)

为了获得最佳体验，建议不要直接在浏览器窗口内使用，而是将其“安装”到桌面：

1.  在 **Safari 浏览器** 中打开你的 App 网址。
2.  点击底部的 **“分享”** 按钮（方块带向上箭头）。
3.  在弹出的菜单中下滑，点击 **“添加到主屏幕”**。
4.  回到桌面，点击图标即可进入无边框的沉浸式模式。

## 📂 PDF 导入操作流

由于 iOS 系统的沙盒机制，网页无法直接访问微信内部文件夹，请按照以下标准流程操作：

1.  **暂存文件**：在微信群点开 PDF -> 点击“用其他应用打开” -> 选择 **“存储到‘文件’”**。
2.  **应用导入**：回到“VEX 大师”App -> 点击“导入” -> 选择 **“选取文件”** -> 选中刚存好的 PDF。

## 🛡️ 隐私与安全说明

* **本地运行**：本工具为纯前端架构，不设后端服务器，不记录任何用户信息。
* **数据隔离**：所有导入的赛程、录入的比分均仅存在于用户本人的设备物理内存中。
* **安全可信**：不申请相册写入权限，海报生成采用 Canvas 渲染 + 手动长按保存模式，完全符合苹果安全规范。
