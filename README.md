# VEX 赛程管理助手 (VEX Schedule Master) v2.6

一款专为 VEX 机器人竞赛教练和队员设计的硬核赛程管理工具。支持 **Android 原生 App** 和 **iOS/PWA** 双端，采用"主干隔离，双线分支"的维护模式。

> **为什么做它**：VEX 官方 App「VEX Via」在安卓上无法正常使用（iOS 正常），本工具补上这块空缺，并面向带队教练做了深度增强——关注队伍、场次提醒、海报分享、中文界面、离线容灾。

> **v2.6 新版亮点**：**自动刷新**（数据页每 30 秒静默同步，切后台自动暂停，头部常驻"上次更新"时间条，达到 Via 级实时体验）+ **单按钮全量同步**（并行抓取 + 接口自动重试，全量同步实测 1.8~2.1 秒，原串行实现约 10 秒）。

## 🌟 核心特性

### 🔄 单按钮全量同步 (v2.5)
「同步比分」与「一键拉取赛程」已合并为一个 **「🔄 云端同步 (赛程/比分/排名/技能赛)」** 按钮，一次点击刷新全部数据：
* 并行抓取（比赛/排名/决赛排名/技能赛/队伍五条链同时发起）+ `per_page=250` 单页拿完
* 网络抖动/5xx 自动重试一次，401/404 等确定性错误不浪费时间
* 多赛事（多 SKU）数据自动聚合；关注队伍列表同步后保留

### 📡 自动刷新 (v2.6)
* 停留在单队/联队/技能页时，每 **30 秒** 静默全量同步，比分自动滚入
* 吸顶状态条常驻显示：**[自动刷新 开/关] · 上次更新时间 · 倒计时**
* 切后台自动暂停省电省流量，回前台数据过期立即补一次
* 同步失败不弹窗打扰，状态条黄色提示「当前为缓存数据」——永远知道数据新鲜度

### 🏆 决赛完整支持 (v2.3)
* 决赛场次独立编号（`F1`、`F2`…），与资格赛 `Q1`、`Q2` 彻底区分，比分互不干扰
* 单队视图中决赛卡片金色标识（左边框 + 🏆 徽章），资格赛/决赛一眼区分
* 决赛时间自动回退实际开赛时间，场次按时间正确排序

### 📊 联队排行榜 (v2.2/v2.4)
* 官方分区积分榜（VEX Via 样式）：名次 🥇🥈🥉/#N + 队号 + 队名 + 官方均分
* **资格赛 / 决赛** 排行一键切换（决赛榜含并列名次，与官网 Finalist Rankings 一致）
* 多赛区（Division A/B + Finals）自动仲裁，大赛区排名不被小赛区覆盖

### 🎯 技能赛排行榜 (v2.4)
* 官方合并口径：名次 + **自动/手动分数与各自场次** + 总分（手动最高 + 自动最高）
* 按年级一键过滤：全部 / 小学 / 初中
* 单队视图同步展示 🎯 技能赛摘要卡（排名/总分/各项分数与场次）

### 🔥 多赛事并发聚合 (v2.1)
* 动态添加多个赛事 SKU（如初中组 + 小学组），一键聚合为一张总表
* 单个 SKU 失败不影响其他赛事，错误信息汇总展示

### 🏅 极简排名静默抓取 (v2.1)
* 同步时自动抓取队伍官方排名，单队视图显示 **🏅 资格赛排名** 金色徽章
* 决赛队伍额外显示 **🏆 决赛排名** 紫色徽章，两种名次不再混淆

### ✨ 智能赛区净化 (v2.1)
* 自动遍历赛事下所有子赛区（Division A、Final…），名称提炼为极简格式
* 单赛区赛事自动显示「默认赛区」，不出现奇怪的「Default区」

### 📶 离线容灾兜底 (v1.0 基石)
* 赛前导入 PDF 即可离线使用，数据基于 LocalStorage 实时存储
* 体育馆无网络环境下依然稳定可靠（云端同步失败时自动提示当前为缓存数据）

### 📱 双端独立架构

| 端 | 技术栈 | 专属特性 | 入口 |
|----|--------|----------|------|
| **Android** | H5+ 原生 App | 海报直接保存到系统相册 (`plus.gallery.save`) | `VEX_Master_Android/` |
| **iOS** | PWA 网页应用 | Safari "添加到主屏幕" 即装即用 | `VexMaster/` |

### 其他经典特性
* **多格式 PDF 高速解析**：导入赛事官方下发的 PDF 对阵表，自动识别赛区、场地、时间、红蓝方联盟
* **单队视图与海报生成**：输入己方队伍号，自动过滤该队所有比赛（含决赛），一键生成分享海报
* **红蓝阵线设计**：视觉上沿袭 VEX 经典的红蓝联队色，配合极简几何 UI，信息层级清晰分明

## 🚀 快速开始

### 方式一：云端同步（比赛日推荐）

1. 获取赛事 **SKU**（赛事通知或 VEX 官网）与 **API Token**（events.vex.com 登录后申请 API 访问）
2. 打开 App → 「数据导入」页 → 填写 SKU 和 Token
3. 点击 **「🔄 云端同步」** 一次 → 赛程/比分/排名/技能赛全部到位
4. 之后切到单队/联队/技能页，**数据每 30 秒自动刷新**，无需手动操作
   * （赛前未开赛时先同步一次拿资格赛对阵表；开赛后每次同步自动带上决赛数据）

### 方式二：本地导入 PDF（完全无网）

1. 在微信群点开 PDF → "用其他应用打开" → "存储到'文件'"
2. 回到 App → 点击"导入" → 选取 PDF

### Android 端 (APK)

1. 使用 **HBuilderX** 打开 `VEX_Master_Android` 文件夹
2. 顶部菜单：`发行` → `原生App-云打包` → 勾选 Android
3. 打包完成后，在 `unpackage/release/apk/` 目录下提取 `.apk` 文件

### iOS 端 (PWA)

1. 将代码推送到 GitHub 仓库（Pages 自动部署）
2. 在 Safari 中打开 App 网址 → 点击"分享" → "添加到主屏幕"

## 📲 iOS 用户安装指南

1. 在 **Safari 浏览器** 中打开 App 网址

## ⚠️ 重要：双端维护原则

**切勿合并双端代码！**

Android 端使用了 H5+ 专属 API（如 `plus.gallery.save` 直接保存海报到相册），这些代码在 iOS 浏览器环境会直接报错阻断运行。请严格遵守 `VEX_Master_Android` 与 `VexMaster` 分离维护的原则。

| 特性 | Android | iOS |
|---|---|---|
| PDF.js 版本 | v2.16.105 | v2.6.347 (兼容老款iPad) |
| CDN 节点 | cdn.staticfile.net | lib.baomitu.com |
| 海报保存 | plus.gallery.save (直接写入相册) | 引导用户长按保存 |
| 键盘适配 | 无 | focusout 防回弹留白 |
| API 存储 Key | `vex_matches` / `vex_scores` / `vex_skills` 等 | `vex_matches_ios` / `vex_scores_ios` / `vex_skills_ios` 等 |

> 同步/场次编号/排名合并等核心逻辑在三份拷贝中必须逐字一致（iOS 内联副本、iOS `vex-api-sync.js`、Android `vex-api-sync.js`），改动后必须跑 `node .zcode/test_rankings.js` 回归。

## 🛡️ 隐私与安全说明

* **本地运行**：本工具为纯前端架构，不设后端服务器，不记录任何用户信息
* **数据隔离**：所有导入的赛程、录入的比分均仅存在于用户本人的设备本地
* **Token 安全**：API Token 仅存储在本地 LocalStorage，不上传至任何第三方服务器
* **安全可信**：iOS 版不申请相册写入权限，海报生成采用 Canvas 渲染 + 手动长按保存模式
